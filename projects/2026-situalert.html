SituAlert

GitHub | Devpost | Video Walkthrough

Aug-Sep 2026 | Agentic AI, React Native, Full-stack development

A mobile app that detects nearby emergencies and provides AI-powered guidance based on verified, official sources. Worked with a partner to build this app for a 1-month hackathon; I was responsible for developing the backend, as well as implementing networking hooks and UI wireframe on frontend.

My main contributions:

  • Participate in initial product scoping and design, making sure our plans were achievable within a 1-month timeframe, but also flexible enough to add and remove features as needed.
  • Architected and implemented backend with Strands Agents SDK for Python. Deployed with Amazon Bedrock AgentCore for agent hosting, AWS Lambda for invocation, and Amazon API Gateway for HTTP endpoints.
  • Set up networking hooks to invoke agents, retrieve shaped agent output, and populate the mobile app UI.
  • Summarize our codebase architecture in a readable diagram for the final presentation. Focused on presenting an explanation that was understandable for a non-technical audience but also detailed enough to engage technical viewers.
