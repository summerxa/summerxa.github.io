LoRA Re-implementation

GitHub | Writeup | Poster

Spring 2026 | ML, Python

Created by Anne Xia, Elliott Lin, Trisha Saini, Samarth Shridhar at Cornell University. Final project for CS 4782, taught by Professors Kilian Q. Weinberger and Wei-Chiu Ma for Spring 2026.

A re-implementation and further exploration of LoRA: Low-Rank Adaptation of Large Language Models (Hu et al., 2021, arXiv:2106.09685). We focused on using LoRA to adapt Facebook AI's pre-trained RoBERTa-base model for sentiment classification on the Stanford Sentiment Treebank (SST-2) dataset; additionally, I investigated the interaction between two of the LoRA adapter's scaling hyperparameters.

My main contributions:

  • Implement full training/validation and testing cycle with checkpointing and automatic backup to cloud storage. Implement and debug model class connecting RoBERTa-base model to LoRA adapter.
  • Independently develop and test research hypotheses going beyond results stated in the paper.
  • Present findings at course's final research panel.
  • Coordinate team discussions and to-dos to ensure on-time delivery of project milestones.

Technologies used:

  • RoBERTa-base model from Facebook AI.
  • Stanford Sentiment Treebank v2 dataset from Stanford NLP.
  • HuggingFace to source base model, tokenizer, and dataset.
  • PyTorch for model architecture, training, validation, and testing.
  • Google Colab for code share, cloud compute, and integration with Google Drive for cloud sync.
