Eta Compiler

Spring 2026 | Kotlin, Compiler design

Worked with Farhan Naqib, Matthew Kim, Chloe Fischer. Final project for CS 4120: Introduction to Compilers, taught by Professor Andrew Myers for Spring 2026 at Cornell University.

A compiler written in Kotlin for Eta, an imperative C-like programming language.

My main contributions:

  • Contribute to codebase architecture design plans, focusing on modular designs so that each team member could work on separate components in parallel.
  • Independently implement and test modules based on architecture plan.
  • Proactively sync with teammates to understand the full codebase, which allowed us to easily debug and test each others' components without extensive onboarding time.
  • Participate in extensive testing of compiler, designing and evaluating edge cases for both my own and my teammates' implemented logic.

Our program includes every step of the compilation process: lexing, parsing, typechecking, intermediate representation (IR) generation, and finally assembly (ASM) code generation.

We also implemented the following optimizations: copy and constant propagation, constant folding, global value numbering, common subexpression elimination, tail-call optimization, function inlining, dead/redundant code elimination, register allocation, and move coalescing.

For more details, the language specifications are as follows:

  • Eta specification
  • Rho specification (an extension to Eta with nulls and record types)
